Privacy Policy

This policy covers Under the Hood Uploader (the "Tool"), a private command-line tool that uploads videos to the Under the Hood channels (YouTube, Instagram, Facebook, TikTok). The Tool is operated by the channel owner, an individual creator based in France.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

TikTok

The Tool also uses the TikTok Login Kit and Content Posting API to send the owner's finished videos as drafts to the owner's own TikTok inbox. It requests only the basic profile (display name, open ID) and the permission to upload drafts. TikTok tokens are stored only on the owner's computer, are never shared, and can be revoked at any time in the TikTok app (Settings and privacy > Security > Manage app permissions). TikTok's handling of data is described in the TikTok Privacy Policy.

Who uses the Tool

Only the channel owner signs in, with their own Google account. No other person can sign in or use the Tool.

What data the Tool accesses

  • An OAuth access token and refresh token for the owner's Google account, with the permission to upload videos (youtube.upload) and to read basic channel information.
  • The IDs, titles and scheduled publish times of the videos the owner uploads.

The Tool does not access, collect or store data about any viewer or any other YouTube user.

How data is used, stored and shared

  • Tokens are stored only on the owner's own computer, in a local configuration file, and are used only to upload the owner's videos.
  • Video IDs are kept in a local log on the same computer so the owner can track publications.
  • No data is sold, shared with or disclosed to any third party.
  • No cookies or tracking technologies are used, on this website or in the Tool.

Retention and deletion

Data is kept only while the Tool is in use. The owner can delete the local files at any time. Access can also be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. After revocation, stored tokens no longer work and are deleted within 7 days.

Changes

Any change to this policy will be published on this page with a new "last updated" date.
